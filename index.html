Still on this screen? Duty Radar has to be served over http or https. Browsers block its program modules and data files when index.html is opened straight from disk, at an address starting with file://.

To run it on your computer, open a terminal in this folder, run npm run serve (or python -m http.server 8080), then open http://localhost:8080. Published on GitHub Pages, it works as is. Use a current Chrome, Edge, Firefox or Safari.
